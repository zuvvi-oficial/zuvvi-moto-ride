# Zuvvi Moto Viagens

Crie um novo projeto chamado Zuvvi.

O Zuvvi será uma plataforma de mobilidade urbana especializada em corridas de moto-táxi no Brasil.

Neste momento, quero apenas iniciar a base do projeto. Não crie ainda as telas do passageiro, telas do motorista, painel administrativo, banco de dados, autenticação, pagamentos, mapas ou outras funcionalidades.
